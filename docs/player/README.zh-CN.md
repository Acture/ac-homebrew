# AC 的房规手册 0.2.1

这是为《**开拓者：正义之怒**》添加房规专长的模组，使用 Unity Mod Manager
（UMM）安装。旧名为 AttributeFeats，安装目录仍是 `Mods/AttributeFeats`。

## 有哪些内容

创建角色或升级时，展开 **AC's Homebrew**，进入专长家族，再选择具体专长。
每次选择只获得一个专长；打开菜单不会额外消耗专长。以后可再次进入家族，
但仍需满足前置条件、互斥组和你启用的额度限制。

- **属性：** 用一个属性强化另一个属性，替换武器攻击或伤害所用属性，
  将衍生数值转为加值，或更换法术书的施法属性、职业资源的额外次数来源。
- **专精：** 将属性调整值用于防御、战技、技能或魔法的主题加值。
- **武技：** 可开关的架势、条件触发、近身／中距／远距风格、触及、连击与处决。
- **防御：** 活性护甲、反击和暂时不死的生存专长。
- **魔法：** 学派／描述符特化、法术位效果与免疫穿透。
- **召唤：** 强化或增量召唤、献祭交换、治疗共享。
- **风格：** 潜行、独行与击杀成长。玩梗专长默认关闭。

`Localization` 文件夹中每种游戏语言各有一个 JSON 文件，包含可直接阅读的名称、
背景与完整规则文本（包括共用描述模板）。它们也是模组实际加载的语言文件，
不是另一套展示文案。修改文字不会修改专长效果。

## 安装

1. 为《正义之怒》安装 [Unity Mod Manager](https://www.nexusmods.com/site/mods/21)。
2. 从 [GitHub Releases](https://github.com/Acture/ac-homebrew/releases) 或
   [Nexus 页面](https://www.nexusmods.com/pathfinderwrathoftherighteous/mods/1217)
   下载 `ACHomebrew-0.2.1.zip`。
3. 在 UMM 中安装该 ZIP，启用 AC's Homebrew。
4. 启动或重启游戏。游戏内通常按 **Ctrl+F10** 打开 UMM 设置。

BlueprintCore 已内置，无需单独安装。ModMenu 和 ModTagEx 均为可选；
安装 ModMenu 后，游戏选项中也会出现本模组的设置页。

## 升级与旧角色

先退出游戏，备份存档和原有 `Mods/AttributeFeats` 文件夹，包括设置与改过的语言文件。
通过 UMM 安装新 ZIP，再把自己的译文合入新版语言文件，保留新增的 key。
不要把旧版和新版作为两个独立模组同时安装。

UMM 身份、设置身份和已发布的专长标识不变。**0.2.1 只改变交付内容和文本加载，
不改变专长机制或数值。** 旧版留下的 `AttributeFeats.dll` 已不是入口程序集；
当前入口为 `ACHomebrew.dll`。

从 0.1.x 升级时，注意 **0.2.0 的玩法变化**：六个旧版广域主属性专长已退役，
旧角色仍保留它们，但效果收窄；重训后可选新的“来源属性→目标属性”专精。
专精、部分架势与触发、召唤献祭和距离风格也有调整，旧角色会使用新版效果。
详见按版本整理的 `CHANGELOG.zh-CN.md` 或英文 `CHANGELOG.md`。
从 0.0.x 升级尤其需要备份：0.1.0 曾重做专长并重置设置。

## 设置与限制

默认 **Balanced** 是预期的基准。`Legacy_AllFull` 使用完整等级配置缩放；
BAB 与 Power Mode 强力选项默认关闭，开启会明显增强效果。

- **武器伤害模式：** Replace（默认）在新属性更高时替换原伤害属性；
  Add 额外加一次正调整值。武器本来就要具有属性伤害加值才会受益。
  切换模式不需要重选专长。
- **专长额度：** 数量上限和点数上限默认均关闭，可单独或同时启用。
  每角色跨所有房规家族计数；菜单、原版及其他模组专长不计。
  参数化专长的每个选择、专长的每级分别计数。调低上限不会移除已有专长，
  但超额期间不能再选新专长。
- **互斥组：** 默认开启，各组可分别调整开关与上限。关闭总开关后不检查这些组；
  施法与资源属性仍是每本法术书／每项资源只能选一个。
- **施法：** 默认只替换选定法术书，并始终替换；可改为影响所有法术书，
  或仅在新属性更高时使用。
- **真·独行：** 默认宠物不抵扣缺席同伴数量。**玩梗专长：** 默认关闭。

武器伤害、额度、互斥组、施法范围／模式和真·独行宠物选项即时生效。
其他开关（包括玩梗菜单）需要重启游戏。属性／专精的对应加值也可由功能开关禁用；
规划构筑前请阅读具体专长规则。

## 语言文件与翻译

游戏语言决定使用哪个文件：英文 `enGB`、简体中文 `zhCN`、德文 `deDE`、法文 `frFR`、
西班牙文 `esES`、意大利文 `itIT`、巴西葡萄牙文 `ptBR`、俄文 `ruRU`。文件中缺少的文字回退为英文。

**德、法、西、意、葡、俄六种语言是机器翻译**，尚未经母语者审校，名称和术语可能生硬，
或与游戏官方译名不一致。欢迎按下文方法修改文件，并通过
[GitHub](https://github.com/Acture/ac-homebrew/issues) 或 Nexus 页面提交更正。
编辑已安装模组 `Localization` 文件夹中的对应 UTF-8 JSON，保存后**重启游戏**即可，
不需要重新编译 DLL。游戏内切换语言会刷新本次启动已登记的文字，
但不会重新读取启动后改过的文件。

不要修改 key。共用模板里的 `{0}`、`{1}` 等编号参数可以换顺序，但不能遗漏，
其格式说明也要保留。保留 `\n` 换行、`<i>`／`<b>` 等富文本标签，以及
`{g|Encyclopedia:Armor}…{/g}` 这类百科链接；可翻译链接显示文字，不要更改链接目标。
JSON 中引号和反斜杠需要转义，最后一项后不能加逗号。

外置文字优先。缺少文件或 key、空译文、无效占位符或标签会回退到内嵌语言文本；
JSON 格式错误则整份文件回退。诊断写入模组的 UMM／游戏日志；
未知 key 会记录并忽略。内嵌中文缺失时先回退英文，再使用代码中的应急文本。

## 已知问题与反馈

这是公开测试版，专长平衡和所有游戏场景下的行为尚未确认。
请备份重要存档，不要直接把未尝试的专长用于不可逆的构筑。

- 法术书界面标题可能仍显示原施法属性。
- UMM 设置面板仍为英文；可选的 ModMenu 设置页为中英双语。
- 六个武器伤害专长尚无专属图标；主属性专精复用来源属性图标。

可在 [GitHub Issues](https://github.com/Acture/ac-homebrew/issues) 或
[Nexus 页面](https://www.nexusmods.com/pathfinderwrathoftherighteous/mods/1217)反馈。
请附模组／游戏版本、专长名称、相关设置、预期与实际结果、复现步骤及相关日志片段。
不要上传游戏文件或个人信息。
